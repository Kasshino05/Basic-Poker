# C# Poker Game

A simple console-based poker game made in C# as part of my programming studies.

## Features
- Creates a standard 52-card deck
- Shuffles the cards randomly
- Supports 2–10 players
- Deals five cards to each player
- Recognizes poker hands
- Compares players' hands and determines a winner
- Detects ties

## Technologies
- C#
- .NET
- Visual Studio

## What I learned
While working on this project, I practiced:
- Classes and objects
- Lists and dictionaries
- Loops and conditional statements
- Methods
- Enums
- Random card shuffling
- Basic poker hand evaluation
